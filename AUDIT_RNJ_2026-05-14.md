# Audit RNJ Advisory
Date: 14 mai 2026 (UTC)
Cible: https://rnj-advisory.be
Périmètre: performance basique HTTP, en-têtes sécurité, cohérence linguistique FR/EN sur pages publiques.

## 1) Résumé exécutif
- Performance serveur: correcte globalement (TTFB ~110 ms à ~171 ms sur les pages principales testées).
- Sécurité HTTP: en-têtes de sécurité manquants (priorité haute).
- Langue: plusieurs libellés visibles en anglais sur des pages FR (priorité moyenne à haute selon objectif 100% FR).

## 3) Sécurité (en-têtes HTTP)
Résultat: en-têtes suivants absents sur les pages testées:
- `Strict-Transport-Security`
- `Content-Security-Policy`
- `X-Frame-Options`
- `X-Content-Type-Options`
- `Referrer-Policy`
- `Permissions-Policy`
- `Cross-Origin-Opener-Policy`
- `Cross-Origin-Resource-Policy`

Points positifs:
- Redirection HTTP -> HTTPS active (301).
- Certificat TLS valide (Let's Encrypt R12, valide du 23 mars 2026 au 21 juin 2026).

### Risque
Sans ces en-têtes, exposition accrue aux risques de clickjacking, MIME sniffing, fuites de referrer et surface XSS plus large.

## 4) Cohérence linguistique (FR/EN)
Objectif demandé: interface 100% française.

### EN visible dans le site public
- `Search...`
- `Contact us`
- `Project 1/67` (format variable)
- `Insights`
- `All`
- `Home`
- `Services` (à valider selon choix éditorial)

### Fichiers source concernés (principaux)
- `src/app/services/analyse-institutionnelle/AnalyseInstitutionnelleClient.tsx`
- `src/app/blogs/page.tsx`
- `src/components/Navbar.tsx`

## 5) Priorités de correction
1. **Haute**: ajouter en-têtes sécurité au niveau Nginx (ou proxy front).
2. **Haute**: imposer HTTPS strict avec HSTS (après validation de tous les sous-domaines).
3. **Moyenne/Haute**: remplacer tous les labels EN restants par FR (pages publiques).
4. **Moyenne**: mettre en place un contrôle CI qui détecte les chaînes EN interdites.

## 6) Correctifs recommandés (concrets)
- Nginx: ajouter (exemple de base)
  - `add_header Strict-Transport-Security "max-age=31536000; includeSubDomains; preload" always;`
  - `add_header X-Content-Type-Options "nosniff" always;`
  - `add_header X-Frame-Options "SAMEORIGIN" always;`
  - `add_header Referrer-Policy "strict-origin-when-cross-origin" always;`
  - `add_header Permissions-Policy "camera=(), microphone=(), geolocation=()" always;`
  - `add_header Cross-Origin-Opener-Policy "same-origin" always;`
  - `add_header Cross-Origin-Resource-Policy "same-origin" always;`
  - `Content-Security-Policy` à construire selon scripts/styles/images réellement utilisés.

- Frontend FR:
  - `Search...` -> `Rechercher...`
  - `Contact us` -> `Contactez-nous`
  - `Project X/Y` -> `Projet X/Y`
  - `Insights` -> `Analyses`
  - `All` -> `Tous`
  - `Home` -> `Accueil`
  - `Services` -> `Services` (garder) ou `Nos services` selon charte.

## 7) Commandes de test utilisées
- Performance: `curl -sS -o /dev/null -w ...`
- En-têtes: `curl -sSI https://rnj-advisory.be/...`
- TLS: `openssl s_client ... | openssl x509 -noout -issuer -subject -dates`
- Recherche EN source: `rg -n '(Contact us|Search...|Project ...|Insights|All)' src`

## 8) Conclusion
Le site est rapide côté serveur, mais la sécurité HTTP doit être renforcée rapidement et la cohérence linguistique FR/EN n'est pas encore complète.
